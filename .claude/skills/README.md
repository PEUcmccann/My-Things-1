# Project skills

These are Matt Pocock's in-progress (beta) skills, copied from
https://github.com/mattpocock/skills/tree/main/skills/in-progress at commit `6f7f783` on 2026-11-27.

| Skill | What it does |
| --- | --- |
| `chief-of-staff` | Delegates work to fresh subagents and keeps a dated wiki so the next session picks up the thread. |
| `claude-handoff` | Hands the conversation to a fresh background agent via `claude --bg`. |
| `loop-me` | Grills you into workflow specs over several sessions (`workflows/*.md`, `NOTES.md`). |
| `setup-ts-deep-modules` | Wires dependency-cruiser into a TypeScript repo so packages are deep modules. |
| `software-factory` | Shared vocabulary for designing a software factory; use alongside a grilling session. |
| `writing-fragments` | Writing, explore: mines raw fragments into one document. |
| `writing-beats` | Writing, exploit: builds an article beat by beat, choose-your-own-adventure style. |
| `writing-shape` | Writing, exploit: shapes raw material into an article paragraph by paragraph. |

All are user-invoked only: type `/<name>`.

They are kept exactly as upstream (Prettier and ESLint ignore this folder), except `chief-of-staff`, whose sibling-skill paths were adapted (see its `SOURCE.md`). Upstream warns these can change or disappear without notice; re-copy from the link above to update.
