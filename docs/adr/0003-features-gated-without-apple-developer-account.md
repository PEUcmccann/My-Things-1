# Native-only features are built but switched off

There is no Apple Developer account, so on iPhone MyThings runs only inside Expo Go or as a web app saved to the Home Screen. Expo Go cannot load a share extension and does not allow background location on iOS. The share sheet and Place Reminders are therefore built into the data model and the code, but stay switched off. They can be turned on if the app is ever built as a standalone iPhone app.
