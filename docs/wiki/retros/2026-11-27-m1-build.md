# Retro: Milestone 1 build (2026-11-27)

A retro, using `anthropic-skills:retro`, on the subagent session that built Milestone 1 (PR #20). The retro ran as a delegated subagent. A usage limit stopped it at about 02:30 UTC, and it was resumed at 04:18 UTC. Its report is the source for this page; it lived in the chief-of-staff session's transcript and was not copied here.

Findings, most severe first, and what the chief of staff did about each on 2026-11-27:

1. **The whole milestone ran in one context window, peaking at about 474k tokens.** The coordinator handed `implement-spec` itself to a subagent, which couldn't start sub-agents of its own. **Offered to the user, not done**, because it changes the chief-of-staff skill. The proposed change is a line in `.claude/skills/chief-of-staff/SKILL.md`: run `implement-spec` from the chief-of-staff session, and delegate only single tickets.
2. **Python string-replace patches silently did nothing after the pre-commit hook re-ran Prettier on the files**, three times. **Done** in `afb975b`: a CLAUDE.md note to re-read files after committing and to prefer the Edit tool.
3. **`@playwright/test` ^1.65 didn't match the preinstalled Chromium 1243**, so UI runs used `/usr/bin/google-chrome`. **Done** in `b9c3110`: pinned to 1.63.0, and `npm run test:ui` added to CLAUDE.md.
4. **No check for Expo SDK versions**, so `^` ranges slipped in. **Done** in `5982996`: `npm run check:expo`, run in pre-commit and CI. It found and fixed `react-dom` and `react-native-web`.
5. **`docs.expo.dev` and Expo's API were blocked.** **Offered to the user, not done**, because it means adding allowed hosts to the environment.
6. **Four copies of the `react-hooks/refs` disable around PanResponder**, plus a debug loop of about 10 iterations on web swipe. **Offered to the user, not done**: either a shared `useLatestPanResponder` hook, or moving to `react-native-gesture-handler` (it's bundled with Expo Go, so ADR 0003 allows it).
7. **Glossary-avoided words in app text weren't linted.** **Done** in `f3b5e66`: an ESLint rule for `src/app/**/*.tsx`. It fixed one string, the Trash note.
8. **The coordinator committed into the subagent's working tree.** **Offered to the user, not done**, because it changes the chief-of-staff skill. The lesson is also in [Cloud session friction](../problems/cloud-session-friction.md).
